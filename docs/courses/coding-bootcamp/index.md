# Coding Bootcamp

Overview of a full-stack Java + web development bootcamp curriculum.

## Curriculum

**First Half (Weeks 1–4) — Java Core**

- Week 1: Java basics, OOP, variables, data types, control flow
- Week 2: Exception handling, Date class, I/O streams
- Week 3: Interfaces, multithreading
- Week 4: Java EE, Hibernate (ORM, enterprise apps)

**Second Half (Weeks 5–8) — Frameworks & Front-End**

- Week 5: Maven, Spring Framework
- Week 6: Spring Boot
- Week 7: React, Capstone
- Week 8: Agile
