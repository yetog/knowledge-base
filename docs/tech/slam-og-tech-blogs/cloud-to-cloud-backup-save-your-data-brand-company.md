# Cloud-to-Cloud Backup - Save Your Data, Brand, & Company

**Source:** https://www.wte.net/Cloud-to-Cloud-Backup-Save-Your-Data,-Brand,-Company  
**Date:** April 2022  
**Author:** Martin W Smith

---

## Introduction

The piece opens by noting that backups and restoration processes have evolved significantly. As systems change constantly, the author emphasizes the importance of protecting mission-critical data and company operations.

## Microsoft's Recommendation

WTE Solutions agrees with Microsoft's guidance to implement third-party backup solutions for Office 365 environments. The firm has assisted customers in establishing cloud-to-cloud backup systems that are described as "fast, granular, easy to use, automatic, and continuous."

## Key Concept: Cloud-to-Cloud Backup

The dual-cloud approach provides redundancy, as simultaneous failures across two cloud providers are extremely rare. The authors note they've experienced individual outages but never concurrent failures.

## Granular Backups Explained

Modern cloud systems enable automatic, continuous backups rather than scheduled nighttime processes. Granularity allows restoration to the closest point-in-time before failure, minimizing data loss.

## Implementation

Configuration typically requires approximately 15 minutes. The system supports restoration from Microsoft Teams, Exchange, SharePoint, and OneDrive, including site templates, custom lists, permissions, and metadata.

## Technical Benefits

Data is deduplicated and compressed to optimize storage and reduce restoration timeframes.
