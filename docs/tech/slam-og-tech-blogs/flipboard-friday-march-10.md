# Flipboard Friday March 10

**Source:** https://www.wte.net/Blog/March-2023/Flipboard-Friday-March-10  
**Date:** March 2023  
**Author:** Martin W Smith

---

This post introduces WTE CEO and Founder Eric Garrison's "Tech Triptych"—three interconnected guides covering emerging technologies:

## Web3

The first component explains "how the decentralized web will change your website, apps, and digital marketing," drawing from Eric's comprehensive Web3 guide.

## Blockchain

The second piece was inspired by a Fast Company article suggesting blockchain adoption would rival cloud computing's pervasiveness, prompting Eric to write about this technological trajectory.

## Cloud Computing

The final guide explores how cloud infrastructure "changes everything," particularly regarding code development and safeguarding critical data.

## Key Connections

The author Martin W Smith notes these technologies form a logical progression: cloud computing creates foundational tools, blockchain builds upon those tools, and both point toward Web3's decentralized architecture. The post also references related content on cloud-to-cloud backups and air-gap backup strategies for data protection.

## Closing Note

The author speculates Eric's next tech triptych may address artificial intelligence, big data, and machine learning.
