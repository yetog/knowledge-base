# Holiday Marketing Tidbits

**Source:** https://www.wte.net/Holiday-Marketing-Tidbits  
**Date:** November 2022  
**Author:** Erica in Client Services

---

## Introduction

The holiday shopping season approaches, and store messaging can drive increased online sales through several strategic approaches.

## Return Policy Messaging

Customers increasingly review return policies before purchasing. According to the article, "businesses with a return policy annotation typically see a 3% increase in average order size and conversion value (according to Google shopping analytics)." Merchants should add return policy details—including item exceptions and extended holiday windows—to product listings using the PointShop Messages function, which requires minimal setup time.

## Shipping Information Display

Approximately two-thirds of customers examine shipping costs and delivery speed before checkout. Displaying complete shipping details prominently helps attract shoppers and can be implemented quickly through PointShop Messages.

## Implementation Instructions

To add messages across all products:

1. Log into SiteAdmin
2. Navigate to the Content menu
3. Select Messages
4. Locate "Product: Text for all products"
5. Click the MANAGE button
6. Include your message and/or link to shipping rates

Users unable to locate this feature should contact Support for assistance.
